# Twitter Sentiment Analyzer

A Python-based sentiment analysis application that classifies tweets and text into:

- Positive
- Negative
- Neutral

## Features

- Analyze individual tweets
- Upload CSV files for batch sentiment analysis
- TF-IDF text feature extraction
- Logistic Regression machine learning model
- Sentiment prediction with confidence scores
- CSV dataset processing
- Interactive Streamlit user interface

## Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- NLTK
- Joblib
- Matplotlib
